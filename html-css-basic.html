第六天：騰波齊寺院——CSS 基礎示範

今天吳Sir抵達了騰波齊寺院（Tengboche Monastery）， 海拔 3860 米。寺院建於 1916 年，是喜馬拉雅山區最著名的藏傳佛教寺院之一。 從寺院可以清楚看到聖母峰、洛子峰（Lhotse）的壯麗景色。

💡 按 F12 → Elements，點選任何元素，右側「Styles」面板會顯示套用了哪些 CSS 規則！ 試試點選標題、段落，觀察 color、font-size、margin 等屬性。

📦 3. CSS 盒模型（Box Model）

每個 HTML 元素都是一個「盒子」，由四個層次組成：

 ┌─────────────────────────────────┐
 │  margin（外邊距，橙色虛線框外）  │
 │  ┌────────────────────────────┐ │
 │  │  border（邊框，綠色）       │ │
 │  │  ┌─────────────────────┐  │ │
 │  │  │  padding（內邊距）   │  │ │
 │  │  │  ┌───────────────┐  │  │ │
 │  │  │  │  content 內容  │  │  │ │
 │  │  │  └───────────────┘  │  │ │
 │  │  └─────────────────────┘  │ │
 │  └────────────────────────────┘ │
 └─────────────────────────────────┘

📦 這是一個示範盒模型的元素

按 F12 → 選此元素 → 右下角「Box Model」可視覺化查看！

✍️ 5. 行內樣式（Inline CSS）

行內樣式直接寫在 HTML 標籤的 style 屬性上：

這段文字使用行內樣式：color: #e34c26; font-size: 1.2rem

行內樣式的優先級最高，但不建議大量使用（難以維護）。

🖼️ 6. 背景樣式（Background）

🏔️ linear-gradient：線性漸層（左上深綠 → 右下淺綠）
background: linear-gradient(135deg, #2c5f2e, #97bc62);
🌄 radial-gradient：放射形漸層（中心橙 → 邊緣紅）
background: radial-gradient(circle, #e8a838, #c0392b);

📏 7. CSS 常用尺寸單位

width: 200px（固定像素）
width: 50%（相對父元素寬度）
width: 20rem（相對根字型大小，20×16=320px）
width: 30vw（相對視窗寬度的 30%）

⚖️ 8. CSS 優先級（Specificity）

當多個 CSS 規則針對同一元素時，優先級決定哪個規則生效：

  1. !important（最高，避免濫用）
  2. 行內樣式（style="..."）
  3. ID 選擇器（#id）
  4. Class / 屬性 / 偽類選擇器（.class, [attr], :hover）
  5. 元素 / 偽元素選擇器（p, h1, ::before）
