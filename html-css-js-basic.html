🎨 7. 直接修改 element.style 屬性

📚 本頁 JavaScript 學習要點

  1. document.getElementById('id')：用 ID 取得元素
  2. document.querySelector('.class')：用 CSS 選擇器取得元素
  3. element.innerHTML = '...'：修改 HTML 內容（可含標籤）
  4. element.textContent = '...'：修改純文字內容
  5. element.style.color = '...'：直接修改行內 CSS
  6. element.classList.add/remove/toggle/contains：操作 CSS 類別
  7. onclick="func()" 和 addEventListener('click', func)：事件監聽
  8. document.createElement('li')：建立新元素
  9. parent.appendChild(child)：新增子元素
  10. element.remove()：移除元素
  11. if / else if / else：條件判斷
  12. switch / case：多分支判斷
  13. parseFloat() parseInt()：字串轉數字
