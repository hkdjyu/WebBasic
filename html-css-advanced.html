🎨 1. CSS 自定義屬性（CSS Variables）

在 :root 定義變數，在整個頁面引用。 修改一個變數，所有使用它的地方都會同步更新！

這個卡片的邊框顏色用 var(--primary)，hover 時變為 var(--accent)。

陰影效果用 var(--shadow)，圓角用 var(--radius)，過渡用 var(--transition)。

只需修改 :root 中的變數，整個設計主題就會改變！（試試在 F12 修改 --primary 的值）

📱 6. 響應式設計（Media Queries）

試試調整瀏覽器視窗寬度，觀察以下方塊的顏色變化：

🖥️ 桌面（>1024px）：綠色 | 📱 平板（≤1024px）：橙色 | 📲 手機（≤600px）：紅色

調整視窗寬度的方法：按 F12 → 點選頂部的「手機圖示」（Toggle Device Toolbar），可以模擬不同裝置！

📚 本頁學習要點總結

  1. CSS 變數：:root { --name: value; } 和 var(--name)
  2. 動畫定義：@keyframes name { from/to 或 0%/100% }
  3. 動畫套用：animation: name duration timing-function delay iteration-count direction fill-mode
  4. 2D 轉換：translate() rotate() scale() skew()
  5. 3D 轉換：perspective rotateX/Y/Z() transform-style: preserve-3d backface-visibility
  6. CSS 濾鏡：filter: grayscale sepia blur brightness contrast hue-rotate saturate drop-shadow
  7. 裁剪：clip-path: circle() polygon()
  8. 響應式：@media (max-width: 600px) { }
  9. position: sticky：捲動時固定元素
  10. clamp()：響應式字型大小
