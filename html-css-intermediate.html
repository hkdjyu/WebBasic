🔍 6. 進階 CSS 選擇器

後代選擇器：.container p（綠色文字）

這段文字是 .advanced-sel-demo 的「後代」p，呈綠色。

子代選擇器：.container > h4（底線）

h4 + p（相鄰兄弟）：這段文字緊接在 h4 後，呈粗體。

h4 ~ p（通用兄弟）：這段也在 h4 後，呈斜體。

📚 本頁學習要點總結

  1. Flexbox：display: flex、justify-content、align-items、flex-wrap、flex-grow
  2. CSS Grid：display: grid、grid-template-columns、repeat()、fr、span、auto-fill、minmax()
  3. 偽類：:hover、:focus、:nth-child、:first-child、:last-child、:not()
  4. 連結偽類：:link、:visited、:hover、:active
  5. 偽元素：::before、::after、::first-letter、::selection
  6. 過渡效果：transition、緩動函數（ease, linear 等）
  7. 進階選擇器：後代、子代（>）、相鄰兄弟（+）、通用兄弟（~）、屬性（[ ]）
